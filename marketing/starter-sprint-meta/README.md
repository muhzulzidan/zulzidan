## Status vocabulary

Use only these values in trackers:

- `BACKLOG`
- `READY`
- `IN_PRODUCTION`
- `IN_REVIEW`
- `APPROVED`
- `SCHEDULED`
- `LIVE`
- `PAUSED`
- `RETIRED`
- `BLOCKED`

## Weekly operating rhythm

1. Monday: update readiness, production tracker, and owners.
2. Wednesday: review drafts against the creative brief and claims checklist.
3. Friday: update the scorecard and record keep/pause/iterate decisions.
4. Never overwrite test history. Add a new row when a hook, audience, offer, or format changes.

## Definition of launch-ready

- Every P0 readiness item is complete.
- At least three distinct creative concepts are approved in both 9:16 and 4:5.
- WhatsApp greeting and qualification questions are tested.
- Every destination URL uses the documented UTM convention.
- Pixel and conversion events are confirmed in Meta Events Manager when the website is used as the destination.
- The person responsible for replying can meet the response-time commitment.
