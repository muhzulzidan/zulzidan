# Asset Workspace

Do not commit raw video, editable production files, private calls, or client-confidential screenshots to Git.

Recommended external folders:

```text
SS-META-001/
  01-raw/
  02-selects/
  03-project-files/
  04-review-exports/
  05-approved/
  06-live/
```

Put the external folder URL in the `source_link` or `final_link` column of the creative tracker. Only add final optimized website assets under `public/` if the site itself needs them.

Before sharing an asset, verify client permission, participant permission, music licensing, and removal of private information.
